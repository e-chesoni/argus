# Argus

A platform-agnostic perception, localization, and mapping framework for heterogeneous robots.

## Overview

Argus is a robotics software project exploring perception, state estimation, and mapping across different robotic platforms and sensor configurations.

The project uses a modular architecture that separates robot-specific hardware from the core perception and mapping stack. The long-term goal is to enable the same localization and mapping tools to operate across wheeled, legged, and other mobile robotic platforms.

Argus is currently under development.
